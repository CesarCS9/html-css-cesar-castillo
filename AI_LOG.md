# AI Usage Log

## Tool Used

- ChatGPT (OpenAI)

---

# Purpose of AI Usage

Artificial Intelligence was used as a learning support and debugging assistant during the development of this project.

The AI assistance focused mainly on:

- Explaining JavaScript concepts
- Helping debug errors and unexpected behavior
- Reviewing code structure and organization
- Improving readability and maintainability
- Guidance for responsive design adjustments
- Suggestions for semantic HTML and accessibility
- Assistance writing documentation files such as the README
- Help understanding API integration and LocalStorage logic

---

# Examples of AI Assistance

## JavaScript Guidance

AI was used to better understand and improve:

- Fetch API with async/await
- Dynamic rendering of products
- Cart state management with LocalStorage
- Filtering and sorting products
- Event listeners and DOM manipulation
- Structuring functions into logical sections

All code was manually reviewed, adjusted and integrated into the final project.

---

## Debugging Support

AI was used to help identify and solve issues such as:

- Incorrect product filtering by gender
- Responsive layout inconsistencies
- CSS alignment problems
- GitHub Pages deployment issues
- JavaScript logic bugs
- Dynamic rendering problems

The debugging process was performed interactively while testing the project manually in the browser and console.

---

## Documentation Support

AI assisted with:

- README structure and formatting
- Writing technical explanations
- Organizing project documentation
- General wording improvements

The final documentation was reviewed and edited manually.

---

# Personal Contribution

All final implementation decisions, testing, styling, debugging and project structure were completed and understood manually.

AI was used as a support tool to reinforce learning and improve workflow efficiency, not as a replacement for understanding the code.
